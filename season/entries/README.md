# Season entries

Enter a hosted season by pull request: add exactly one file here named
`<your-github-login>-<n>.json` (login lowercased, `n` starting at 1) — a
challenge submission (`schema`, `challenge`, `programs`, `agent`). The
Season entry workflow validates the entry, scores it on withheld cases,
commits the result under `season/results/`, and closes the PR. See
docs/seasons.md.
